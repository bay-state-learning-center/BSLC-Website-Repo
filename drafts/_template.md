Write your post here, in plain text.

Leave a blank line between paragraphs, like this one.

Use **two asterisks** for bold, and *single asterisks* for italics.

Start a line with "## " for a section heading.

To add a photo partway through the post, put it on its own line like this:

![Description of the photo, for accessibility](your-photo.webp)

To add a bulleted list, start each line with "- ":

- First point
- Second point

Need something fancier -- a linked image, a downloadable file, or anything
else this doesn't cover? Start the line with "<" and write it directly as
HTML -- it'll be included exactly as written. Ask Amelia if you're not
sure how.
